# Network Intrusion Detection Web App (Deployment Mirror)

This repository mirrors the Flask-based network intrusion-detection web app in [IT254-WebDevProject-vercel](https://github.com/Prajwal-Kadri/IT254-WebDevProject-vercel).

The application uses a trained random-forest model and the UNSW-NB15 dataset to provide form-based intrusion predictions.

## Run locally

```bash
python -m pip install -r requirements.txt
python main.py
```

For project structure and further documentation, see the canonical repository linked above.
